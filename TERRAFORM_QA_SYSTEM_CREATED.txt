  Final: Batch Review
    → python qa_system.py missing  # Check all are filled
    → Claude reviews entire terraform_qa_database.json (1 API call)

================================================================================
TOKEN OPTIMIZATION
================================================================================

Traditional approach (per-question):
  Q1 → Claude API call
  Q2 → Claude API call
  ... 20+ more API calls ...
  Total: ~10,000 tokens, ~20 API calls

QA System approach (batch):
  Phase 1-6: User fills JSON directly (no LLM)
  Final: Claude reviews all at once (1 API call)
  Total: ~2,000 tokens, 1 API call

SAVINGS: 80%+ fewer tokens, 95%+ fewer API calls

KEY FEATURES
================================================================================

✅ No per-question LLM calls
   → Answers collected directly in JSON, not via Claude

✅ Structured JSON format
   → Easy to edit, validate, and persist across sessions

✅ Phase-based organization
   → Separate question templates for each workflow phase

✅ Validation built-in
   → Check completeness before proceeding to next phase

✅ Batch review capability
   → Single Claude API call reviews all answers at the end

✅ Markdown export
   → Convert Q&A to human-readable format for handoff

✅ Status tracking
   → See progress across all phases at a glance

✅ Zero external dependencies
   → Pure Python + JSON, no packages required

CUSTOMIZATION
================================================================================

Add questions to a phase:
  1. Edit: .claude/skills/terraform-from-diagram/qa/{PHASE}_questions.json
  2. Add to "questions" array
  3. Run: python qa_system.py init {PHASE}
  4. New questions will be added to terraform_qa_database.json

Create a new phase:
  1. Create: {NEW_PHASE}_questions.json with same structure
  2. Run: python qa_system.py init NEW_PHASE
  3. Answers auto-populate into terraform_qa_database.json
